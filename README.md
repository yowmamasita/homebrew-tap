# homebrew-tap

All my Homebrew taps and formulae.

```sh
brew tap yowmamasita/tap
```

## Casks

| Cask | Description |
| --- | --- |
| [`mdview`](https://github.com/yowmamasita/mdview) | Lightweight viewer for Markdown with Mermaid diagrams |

```sh
brew install --cask yowmamasita/tap/mdview
```

That installs `mdview.app` into `/Applications` and links the `mdview` command
onto your `PATH`. The build is signed with a Developer ID certificate and
notarised by Apple, so it opens without a Gatekeeper warning.
